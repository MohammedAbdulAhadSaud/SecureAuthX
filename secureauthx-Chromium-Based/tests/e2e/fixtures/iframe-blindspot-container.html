Iframe blind-spot container page

This top-level page performs NO fingerprinting behavior of its own. The only fingerprinting call anywhere on this page tree happens inside the iframe below, in its own separate document (iframe-blindspot-inner.html). Any detection that occurs when this page is scanned can only have come from inside that iframe.

Historical note (Phase 2B-A, now fixed in Phase 2B): this page was originally built to document a known limitation — SecureAuthX's content scripts did not run inside iframes, so the fingerprinting call made inside the iframe below was invisible to the extension. As of Phase 2B, all_frames is enabled and background.js aggregates fingerprint techniques across frames, so this same iframe-only call is now correctly detected. This page is kept as the same fixture that documented the original gap, now serving as the regression test confirming the fix.
