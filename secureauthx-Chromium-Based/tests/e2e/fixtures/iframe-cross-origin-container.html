Cross-origin iframe container page

This top-level page performs NO fingerprinting behavior of its own. The iframe below is served from a DIFFERENT port than this container page — a different port means a different origin per the browser's same-origin policy, giving a simple, realistic way to test cross-origin iframe coverage without needing real separate domains. The iframe's own content (iframe-blindspot-inner.html, the same fixture reused from the same-origin test) performs the fingerprinting call automatically on load.
