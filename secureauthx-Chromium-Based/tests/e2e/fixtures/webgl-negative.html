WebGL Fingerprint Detector — NEGATIVE / Control Test

Local diagnostic page only. Not part of SecureAuthX. This page performs ordinary WebGL rendering and feature-detection — the kind any legitimate game, map, or 3D demo does — and deliberately never touches WEBGL_debug_renderer_info, UNMASKED_VENDOR_WEBGL, or UNMASKED_RENDERER_WEBGL. Nothing is sent anywhere.
How to use this page: open the SecureAuthX popup and check the Fingerprinting section both before and after this page renders (rendering happens automatically on load — no button needed, since none of this is meant to look suspicious in the first place). Expected: Fingerprinting 0, "No fingerprinting techniques detected", no webglDebugInfo entry.
